C# Terminology

Class:
A blueprint/template for creating objects.

Object:
A thing created from a class.

Instance:
An object created from a class.
Example: Student student = new Student();

Reference:
A variable that refers to an object in memory.
Example: student refers to the Student object.

Implementation:
The actual code that defines how something works.

Abstract:
A class/member that is incomplete and meant to be implemented by derived classes.
Abstract class → cannot be instantiated, but can be inherited.

Sealed:
Prevents inheritance.
A sealed class can still be instantiated.

Static:
Belongs to the class itself, not to an instance.
Static members can be used without creating an object.

Static Class:
Cannot be instantiated or inherited.
A static class is implicitly sealed.

Virtual:
Provides a default implementation that derived classes can optionally override.

Abstract Method:
Has no implementation.
Derived classes must implement it.

Override:
Provides a new implementation for an inherited virtual or abstract member.

Inheritance:
A class derives from another class and inherits its members.

Polymorphism:
The same base type can refer to different derived types, with each providing its own behavior.

Extension Method:
Adds a method to an existing type without modifying the original type.

Abstract members are implicitly virtual and must be overridden by derived classes.
Sealed prevents further inheritance or overriding.

Interface:

An interface is a contract that defines what a class must do, not how it does it.

Key Points:
- A class that implements an interface must implement its required members.
- A class can implement multiple interfaces.
- An interface cannot be instantiated directly.
- Interface names usually start with I (e.g., IAnimal, ILogger).
The methods in Interfaces are virtual.
